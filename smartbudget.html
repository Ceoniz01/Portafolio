Caso de Estudio: SmartBudget

Descripción del proyecto

SmartBudget es un prototipo de billetera digital diseñado para ayudar a los usuarios a organizar y visualizar sus finanzas personales de manera simple y eficiente.

Desafío principal

El principal desafío fue estructurar una interfaz clara y escalable utilizando buenas prácticas de CSS, manteniendo el código organizado y reutilizable.

Solución propuesta

Se implementó la metodología BEM para organizar los estilos y se utilizó SASS para mejorar la modularidad y mantenibilidad del código CSS.

Herramientas utilizadas

  • HTML
  • SASS
  • Metodología BEM

Aprendizajes

  • Organización de estilos con BEM
  • Uso de SASS para mejorar la escalabilidad del CSS
  • Buenas prácticas en estructuración de proyectos frontend

Métricas de impacto

  • Mejora en la organización del código CSS
  • Reducción de redundancia en estilos
  • Mayor facilidad de mantenimiento

Habilidades aplicadas

  • Maquetación web
  • Arquitectura CSS
  • Resolución de problemas de diseño

¿Por qué elegí este proyecto?

Elegí este proyecto porque representa mi aprendizaje en la estructuración profesional de estilos y el uso de herramientas modernas como SASS, siendo un paso importante en mi desarrollo como frontend developer.
